# SuporteInTech — Criação de Sites, Desenvolvimento de Software Sob Medida, Cloud & MCPs

> Da infraestrutura à tela, nós construímos o futuro. ## Nossos Serviços Especializados

### 1. Estruturação de Cloud Computing — Arquitetura em Nuvem & Alta Resiliência
Planejamento, provisionamento e governança de ambientes em nuvem com foco em escalabilidade, alta disponibilidade e redução de custos operacionais (FinOps).
- **Tecnologias:** AWS, Google Cloud (GCP), Cloudflare, Vercel, Docker, Terraform (IaC), CI/CD pipelines e monitoramento contínuo.

### 2. Engenharia de Software — Criação de Sites Profissionais & Sistemas Sob Medida
Construção de sites institucionais rápidos, landing pages de alta conversão, portais web, APIs corporativas e sistemas escaláveis sob medida para empresas de todos os portes.
- **Tecnologias:** Java, Spring Boot, Next.js, React, TypeScript, Tailwind CSS, PostgreSQL, Cloudflare R2 / AWS.

### 3. Inteligência Artificial & MCP — Criação de MCPs (Model Context Protocol)
Criação e homologação de servidores MCP customizados e ferramentas especializadas para conectar LLMs e agentes de IA a bancos de dados legados, APIs proprietárias e sistemas internos.
- **Padrões:** Model Context Protocol (Anthropic/Open standard), Tool Calling, Context Providers, Sandboxing e controle granular de permissões.
